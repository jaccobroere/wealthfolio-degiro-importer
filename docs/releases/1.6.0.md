# DEGIRO Importer 1.6.0

## Highlights

- **The right listing, in your currency.** Yahoo's ISIN search returns only a
  security's primary listing — for many UCITS ETFs that is London in GBp — and
  the old "accept all unambiguous matches" took it because it was the only
  result. The importer now searches broadly (the ISIN, the ticker it reveals,
  the instrument's full name and the DEGIRO product name) and ranks listings:
  the same instrument first, then the currency you traded it in on DEGIRO,
  then your preferred exchanges.

- **Accept suggested listings.** The bulk action accepts a listing only when
  it is the same instrument, in your traded currency, and strictly first on
  your exchange preference. Anything else — ties, only other currencies, no
  results — stays for your review with the ranked choices shown.

- **Search anything, pick anything.** Every instrument has its own search box
  (e.g. `IWDA.AS`, a fund name). Results show the exchange, MIC, currency and
  instrument name, with badges for the suggestion, the traded currency, and
  listings that look like a different instrument. A confirmed mapping can be
  changed from the mapping step.

- **Preferred exchanges per account.** Default: Amsterdam, Xetra, Paris,
  Brussels, Milan, Madrid, Lisbon, Frankfurt, then the main US venues. Edit
  the order in the mapping step; it is saved for the account.

- **Forget remembered mappings.** One button (with confirmation) clears every
  mapping this importer remembers for the selected account. Other importers'
  mappings are untouched.

- Remembered mappings are re-verified against their own listing (e.g.
  `IWDA.AS`) instead of the ISIN search, so a correct euro listing is no longer
  reported as stale.

## Measured

On a private 34-security DEGIRO statement against a Wealthfolio 3.6.1 host:
the ISIN-only search returned a single listing for 28 securities, 8 of them in
the wrong currency. The new ranking suggested a listing for 31–32 (Yahoo
results vary slightly between runs), every one in the currency the security
was traded in; the rest were a bond without a euro listing, a security without
results and a tie, all left for review.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
