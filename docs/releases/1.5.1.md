# DEGIRO Importer 1.5.1

Follow-up hardening found while applying the 1.5.0 fixes to the Revolut
importer, verified against a Wealthfolio 3.6.1 server.

## Fixes

- **Same-day repeats of cash-type activities are kept.** Wealthfolio stores
  deposits, withdrawals, fees, taxes and credits without a security, so its
  duplicate key ignores their ISIN. Two equal dividend-tax rows for different
  securities on one day therefore collided and one was dropped. Repeat
  numbering now ignores the security for these types too.
- **Cash-type rows never create a security.** A tax or fee row carrying an
  ISIN no longer triggers the security-creation step; Wealthfolio stores it as
  cash anyway.
- **Trades match across importer versions.** Matching against the account
  compares trades on quantity (plus day, type, currency and security) rather
  than on trade value, so a copy stored by another version with a slightly
  different unit price is still recognised.

## Compatibility

- Wealthfolio: 3.6.1
- Add-on SDK: 3.6.1
